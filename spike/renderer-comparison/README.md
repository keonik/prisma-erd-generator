# Renderer comparison (#102, #313)

The repo's own `prisma/schema.prisma` rendered by both renderers, generated by
the shipped code in #313 — not by a throwaway script.

| file | renderer | how it was produced |
| --- | --- | --- |
| `mermaid.svg` / `.png` | `mermaid` (default) | `mmdc` + Chromium |
| `graphviz.svg` / `.png` | `graphviz` | `@hpcc-js/wasm-graphviz`, no browser |
| `mermaid-nohtml.svg` / `.png` | `mermaid` | historical: `htmlLabels: false`, now the default (#245) |
| `dot.mjs`, `erd.dot` | — | the original throwaway spike, kept for reference |

| | mermaid | graphviz |
| --- | --- | --- |
| install | ~570 MB | 2 MB |
| render | 0.62s | 0.05s |
| SVG | 184 KB | 37 KB |

The `.png` files are rendered with librsvg, which ignores `<foreignObject>` the
same way Inkscape does. Both renderers now produce plain `<text>`, so both
render correctly outside a browser.
